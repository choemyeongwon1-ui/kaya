# 서울숲 「부담 없는 숲」 — 최명원 실험본

개인 디벨롭 실험본입니다. 팀 대시보드를 복사해 목표 3 「부담지도 전략」 탭을 추가했습니다.

- 컨셉: 돈 없이 머물 곳이 없는 성수동에서, 유일한 무료 쉼터인 서울숲을 폭염·미세먼지에도 취약계층까지 부담 없이 머무는 공원으로
- 목표 ① 기후 반응형 맞춤 프로그램 (모듈 1·2·3) · 목표 ② 취약지역 진단과 개선 우선순위 (격자 중첩)
- 결과물: 「부담지도」 — 시민 이용 → 데이터 누적 → 관리자 처방

## 실행
```
cd web_최명원버전
npm install
npm run dev        # 브라우저에서 #burden 탭
```

## 데이터 다시 만들기
```
cd 부담지도
python src/build.py   # web_최명원버전/public/data/burden.json 생성
```

참고: 수치는 OSM 집계·모델 추정값이며, 기준값(체감온도 31/33℃, PM2.5 36/76)은 주제서 예시입니다.
