## 항목별 내용

**① 대상지 계획단위 가설 — 중심·경계·기각조건**

가설 H3 = "종로구청 반경 400 m 는 페리(1929)의 근린주구 한 단위로 읽을 수 있다".
기각조건 R1(초등학교 0개)·R2(간선도로가 경계가 아니라 관통)·R3(근린공원 0개)을 **데이터를 보기 전에** 적었다.

| 조건 | 결과 | 판정 |
|---|---|---|
| R1 초등학교 | 400 m 안 **0개** · 최근접 서울덕수초 698 m | 충족 → 기각 |
| R2 간선도로 | 반경 700 m 내 12개 노선 중 **8개 노선**이 400 m 원 안까지 들어옴 (세종대로 159 m, 사직로 243 m, 율곡로 255 m …) | 충족 → 기각 |
| R3 근린공원 | 400 m 안 **0개** (공원 4개는 모두 소공원·광장) · 최근접 내수2근린공원 671 m | 충족 → 기각 |

세 조건이 모두 충족되어 **H3 기각**. 기각의 뜻은 이론이 틀렸다는 것이 아니라 대상지의 전제가 다르다는 것이므로,
달라진 지점(학령인구·경계의 성격)과 대체 중심시설(광화문역 279 m), 그리고 대상지에 필요한 계보(분리가 아니라 **연결 = TND**)를 함께 적었다.

**② 법령 검증 로그**

7행. 오류 유형 조문 2 · 시점 3 · 수치 2, 판정 실재하지 않음 4 · 시점 불일치 2 · 일치 1.
모든 행에 원문·식별자·시행일·조회일 네 칸과 정정값을 채웠다. 대표 3건:

- **V3-1 (조문)** 「서울특별시 종로구 도시계획 조례」(MST 1746853)에는 용도지역별 건폐율·용적률 조문이 **없다**.
  시행령 제84조제1항·제85조제1항의 위임 대상이 "특별시·광역시·특별자치시·특별자치도·시 또는 군"이고 자치구는 위임 대상이 아니기 때문이다.
  → 정정: 「서울특별시 도시계획 조례」 제44조·제48조.
- **V3-2 (시점)** 강의자료 [2]의 시행령 "2026-09-08 공포·시행"은 조회일 기준 연혁으로 내려갔다.
  현행은 대통령령 제36587호(시행 2026-09-18, MST 288857). 다만 제84·85조의 21종 범위 수치는 두 판본이 같다.
- **V3-3 (수치)** 강의자료 [1]의 "법률 제21284호"는 시행일자별 연혁 28건 어디에도 없다. → 정정: **법률 제21447호**.

**③ 조례 21종 표**

법 제77·78조(대분류 9갈래 상한) → 시행령 제84·85조(21종 범위) → 서울특별시 도시계획 조례 제44·48조(적용값) 세 층을 한 행에 놓았다.
**서울시 조례는 도시지역 16종만 정한다.** 17~21행(보전관리·생산관리·계획관리·농림·자연환경보전)은 '조회 실패'가 아니라
**'조례 미규정 — 관할구역 내 미지정'** 으로 사유를 적고 시행령 범위만 남겼다. 임의 값을 넣지 않았다.

## 조회에서 걸린 것

- **법령 API** — `law.go.kr` 과 `open.law.go.kr` 은 계정이 별개다. 이번 조회는 법제처 공개 데모 키 `OC=test` 로 했다.
  OC 가 틀렸을 때도 응답 문구가 "서버장비의 IP주소 및 도메인주소 등록 요망"으로 나와 IP 탓으로 오진하기 쉽다.
  HTTP 상태는 거절일 때도 200 이므로 **상태 코드만 보고 성공으로 기록하면 로그가 거짓이 된다** — 본문에 `result`·`msg` 칸이 있으면 거절이다.
  본문은 `target=law` + `MST` 로 받는다(`target=eflaw` 는 시행일자별 **목록 전용**).
  응답은 UTF-8 이라 Windows 콘솔에서는 `PYTHONIOENCODING=utf-8` 이 필요하다.
- **Overpass 504** — 본 서버가 Gateway Timeout 을 반복해 돌려주어 `계측_400m원.py` 에 미러 3곳을 순회하는 재시도를 넣었다.
