## 팀 컨셉: 만족도 높은 공원

- **쾌적 시간**: 06~21시 중 비·추위·미세먼지·더위·자외선 기준을 모두 통과한 시간을 격자마다 셉니다. 햇볕에 노출된 칸은 더위와 자외선을, 도로에 가까운 칸은 미세먼지를 더 높게 봅니다.
- **만족도 격차 지도**: 설문 구역 8곳의 취약도와 설문 만족도를 겹쳐 우선 개선 / 숨은 위험 / 운영 문제 / 유지로 나눕니다. 설문 전이라 화면의 만족도는 팀 가설값이고, 탭 안의 입력칸에 설문 평균을 넣으면 판정이 바뀝니다(입력은 브라우저에 저장).

## 다시 만들기

`data/raw/`는 팀 `.gitignore` 규칙대로 올리지 않았습니다. 이 폴더에서 아래 순서로 실행합니다.

```
python analysis/01_fetch.py .
python analysis/02_vulnerability.py .
python analysis/03_climate.py .
python analysis/05_concept.py .
python analysis/04_build.py .
```

필요 패키지: geopandas, rasterio, networkx, scipy, requests, pandas. 위성 검색 결과는 실행 날짜에 따라 장면이 늘 수 있어 수치가 조금 달라질 수 있습니다.

`analysis/dashboard_template.html`에서 고치는 곳 (고친 뒤 `04_build.py`만 다시 실행):

- 진행상태 표: `PROGRESS` 배열
- 구역별 만족도 가설값과 근거: `HYPO`, 항목 중요도 가설값: `IMP_H`
- 설문 구역 구분은 `analysis/05_concept.py`의 `SZ` (고친 뒤 `05_concept.py`부터 다시 실행)

## 주의할 점

- OSM 서울숲 경계에 **뚝도아리수정수센터(60,214㎡)** 가 들어 있어 제외했습니다. **청계천용수공급지**는 부지 성격을 확인하기 전까지 보류 구역으로 두었습니다.
- 열만 실측 위성 자료이고, 대기는 도로 거리, 접근성·혼잡은 보행망 기반 대리지표입니다. 현장 계수와 만족도 설문은 아직 하지 않았습니다.
- 지표 가중치(열 35·접근성 25·대기 25·혼잡 15)와 지표 안의 배분은 근거 문헌이나 전문가 조사 없이 정한 가안입니다. 취약 등급도 상위 20%라는 상대 기준입니다.
- 개선 후 수치는 시나리오 추정입니다.
- **쾌적 시간의 가정**: 햇볕 아래 체감 가산 3℃, 도로변 미세먼지 가산 20%, 추위 기준 0℃는 측정 근거가 없는 가정입니다. 대시보드에서 값을 바꿔 볼 수 있고, 현장 측정으로 확인이 필요합니다. 미세먼지는 CAMS 모델값이라 실측과 차이가 납니다.
- **만족도는 가설값**: 설문 전까지 화면의 만족도와 4분면 판정은 조사 결과가 아닙니다. 11~12월 조사라 여름 더위 항목은 회상 응답이 됩니다.
