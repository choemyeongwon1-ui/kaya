## 말로 조문을 받는 네 단계 — 실행 기록

| 단계 | 한 일 | 받은 값 |
|---|---|---|
| ① 법령 찾기 | `target=ordin` 으로 '도시계획 조례' 검색 후 기관명이 서울특별시인 본청 조례를 고름 | 서울특별시 도시계획 조례 |
| ② 식별자 확인 | 자치법규ID·MST·시행일 확인 | ID 2000719 · MST 2149501 · 시행 2026-07-13 |
| ③ 조문 조회 | 제44조(건폐율)·제48조(용적률) 원문 수신 | 각 16개 호 |
| ④ 조회일 기록 | 응답에 조회일 칸이 없어 직접 기록 | 2026-09-21 |

**④가 필요한 이유 — 응답으로 확인함.** 국토계획법 제2조를 `JO=000200` 으로 조회해 응답의 칸을 전수 확인한 결과
법령명·조·번호(법령ID 009294 / 공포번호 21447)·시행일(20260701)은 응답 안에 있으나 **조회일 칸은 존재하지 않는다.**
응답 전체를 오늘 날짜로 검색해도 나오지 않는다. 조회일은 서버가 주지 않으므로 호출한 쪽이 적어야 하는 값이다.
