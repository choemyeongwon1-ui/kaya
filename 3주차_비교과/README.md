## 강의자료 대조

12쪽 예시는 「제36조(용도지역의 **변경**)」 으로 적혀 있으나 원문 조제목은 「제36조(용도지역의 **지정**)」 이고,
예시 본문의 "1. 토지의 효율적 이용 / 2. 도시의 기능 증진 / 3. 환경의 보전" 도 제36조에 없다.
해당 쪽은 AI 생성 이미지이므로 판정은 '실재하지 않음'이 아니라 **생성물 오기**로 적는다.
