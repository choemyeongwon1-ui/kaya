# 링별 건물밀도 위성지도 (최승하)

### ▶ [**지도 열기**](https://choemyeongwon1-ui.github.io/jongno-building-density/ring_density/) ◀

2주차 2차시 「데이터로 하는 이론 검정」 — 과제 ② **1km 링별 밀도 집계표**용 화면입니다.
위성지도를 배경으로 종로구청 중심 1km 간격 링의 건물밀도(동/km²)를 원그래프·막대그래프·밀도 격자로 보여 주고,
원그래프 안의 밀도 값으로 가설을 판정합니다.

## 기능

- **베이스맵 토글**: 위성 영상(기본) ↔ OpenStreetMap, 베이스맵 켜기/끄기
- **반경 조정**: 1~5km, 0.5km 단위 슬라이더와 1km 단위 빠른 버튼
- **원그래프(지도 위)**: 링마다 하나씩, 가운데 숫자 = 링 건물밀도, 채워진 비율 = 정점 링 대비 밀도
- **막대그래프**: 링별 건물밀도, 링이 3개 이상이면 클라크(1951) 지수감소 예측선을 겹쳐 표시
- **밀도 격자**: 250m / 500m 격자 건물밀도 (가변공간단위 비교용)
- **밀도 분석**: 원그래프 값으로 링 간 변화, 단일중심, 중심부 함몰, 단조 감소, 클라크 지수감소를 자동 판정
- **링별 밀도 집계표**: CSV 저장 버튼 포함 (과제 제출용 CSV 원본)
- **가설 검정 네 단계 · 데이터 카탈로그**

## 결과 요약 (반경 5km)

| 링 | 밀도(동/km²) | 정점 대비 | 전 링 대비 |
|---|---:|---:|---:|
| 0–1km | 1,261 | 100% | — |
| 1–2km | 935 | 74% | −26% |
| 2–3km | 390 | 31% | −58% |
| 3–4km | 373 | 30% | −4% |
| 4–5km | 387 | 31% | +4% |

- 0–1km가 정점이므로 단일중심 가설은 기각되지 않음
- 4–5km에서 다시 오르므로 단조 감소는 기각됨 (반경 3km까지만 보면 단조 감소) — 슬라이드 36p와 같은 모양
- 클라크 지수감소 적합: D(r) ≈ 1,321·e^(−0.33r), R² ≈ 0.80
- 건물 동수 밀도이지 인구밀도가 아님

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 완성된 화면 (데이터 포함) |
| `src/template.html` | 화면 원본 — 데이터 자리에 `__DATA__` 등 자리표시자 |
| `src/build.ps1` | `raw/`의 Overpass 응답을 템플릿에 채워 `index.html`을 다시 만듦 |

`raw/`는 저장소 `.gitignore` 규칙대로 올리지 않았습니다. 다시 받아서 만들려면:

```
powershell -ExecutionPolicy Bypass -File ring_density\src\build.ps1 -Fetch
```
