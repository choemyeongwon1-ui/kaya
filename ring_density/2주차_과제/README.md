## ① 개념 다이어그램

버제스(1925) 동심원을 대상지에 대입함. 반경 3km 안에서는 밀도가 중심에서 바깥으로 계속 낮아져 동심원과 같은 모양이지만, 4–5km에서 다시 올라 통근자지대로 이어지지 않음 → 바깥은 다핵심(해리스·울만)이 필요하고, 단절 원인은 침입-계승이 아니라 산지 지형과 문화재 보존구역임.

## ③ 스마트공원 우선순위 — 열린송현 녹지광장(33,917m², 중심에서 413m)

주변 500m 건물밀도 1,421동/km²(반경 3km 평균 669의 2.12배)를 효과 점수에 반영함.

- 1순위(바로 도입): 보행자 자동 계수(비영상), 토양 센서·관수 모니터링, 데이터 플랫폼(공유 폴더 수준), 스마트 벤치, 스마트 쓰레기통
- 2순위(단계 도입): 스마트 조명, 우수 관리 모니터링, 스마트 음수대, 디지털 안내 표지
- 4순위(보류): 미디어 파사드, 스마트 주차장

효과 = 기본 점수 + 주변 밀도·공원 면적 보정, 난이도 = 강의자료 52쪽 SWOT의 약점·위협 반영 고정 점수. 점수는 강의자료 근거로 정한 판단값이며 실측 비용·효과가 아님.
