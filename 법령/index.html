법령 검증 기록

팀이 인용하는 법령·조례의 법령ID · 시행일 · 소관기관 · 검색시점을 조회할 때마다 검색 응답과 본문 응답으로 대조한 표입니다. 원본은 조회기록.csv이고, 예전 줄은 고치거나 지우지 않습니다.

확인 방법 — 법령ID·시행일·기관: 검색(lawSearch) 응답과 본문(lawService) 응답의 값이 같으면 ✓ · 검색시점: 조회일에 시행 중인지(시행일 ≤ 조회일)와 시행예정 개정본 유무 · 직전 기록 대비: 같은 조의 앞 기록과 MST(일련번호)가 다르면 "버전 바뀜"
새로 조회하기: 저장소 최상위에서 powershell -ExecutionPolicy Bypass -File 법령\check.ps1 (인증키는 환경변수 LAW_OC에만) · 대상 추가: 대상목록.csv · 출처: 국가법령정보 공동활용 OPEN API (law.go.kr)
