## 항목별 내용

**① 버제스(1925) 동심원지대 이론의 대상지 대입**
건물밀도가 1,256.1 → 930.1 → 403.3동/㎢로 단조 감소(R1이 R3의 3.1배)하고,
용도가 확인된 건물 중 상업·업무 비율은 71.6% → 51.9% → 41.5%로 낮아지는 반면
주거는 21.2% → 35.9% → 38.8%로 높아져 이론의 두 예측이 모두 성립한다.
다만 용도 태그 기재율 자체가 30.7% → 25.2% → 22.4%로 바깥일수록 낮아, 용도 구성비는
표본이 얇아지는 점을 함께 밝혔다.

**② 1km 링별 밀도표**
개수가 아니라 밀도(동/㎢)로 환산했다. 개수로는 R2(8,766동)가 R1(3,946동)의 2.2배지만
면적으로 나누면 R1이 R2의 1.35배로 순위가 뒤집힌다 — 밀도 환산이 필요한 이유.

**③ 스마트공원 요소 우선순위표**
효과 × 난이도 2축 5점 척도, 요소 12개. 판정 규칙을 명시해 재현 가능하게 했고,
적용권역은 ②표의 링별 밀도·용도 구성에서 도출했다.

## 팀 내 교차검증

같은 대상지를 팀원 최명원이 Python으로 집계한 `../과제2_링별밀도표_원본.csv`와 대조했다.

| 권역 | 본 표 밀도 | 최명원 표 밀도 | 차이 |
|---|---:|---:|---:|
| 0–1km | 1,256.1 | 1,263.4 | −0.6% |
| 1–2km | 930.1 | 940.0 | −1.1% |
| 2–3km | 403.3 | 407.0 | −0.9% |

세 권역 모두 1.1% 이내로 일치한다. 서로 다른 언어·다른 코드로 독립 집계해 같은 결론에
도달했다. 차이의 원인은 ⑴ 본 표가 중심점 기준 3km 초과 146동을 제외한 점, ⑵ 2차 판정
태그 범위가 조금 다른 점이다.
